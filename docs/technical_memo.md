# 검토용 기술 메모 (초안) — 한국 BESS 사업 평가에서 SMP 차익거래 분석과 계약 조건 분석의 차이

작성 기준일 2026-09-27 · 저장소 `yeongnam-bess-npv` (로컬 커밋, 미공개) · 근거 문서:
`docs/model_audit.md`(A), `docs/market_rules.md`(원문 조항), `docs/contract_model_design.md`(B 계산 내역)

## 1쪽. 연구 질문과 A의 검증된 계산 결과

**연구 질문.** 한국 BESS 사업을 평가할 때 SMP 차익거래 분석으로 무엇까지 판단할 수 있고, 실제 계약의 보상·성능 조건을 반영하면 어떤 사업 판단이 추가로 필요한가?

**분석 구조.**

- **A**: 2024년 관측 SMP로 차익거래만 하는 가상 설비(100MW / 내부 저장 400MWh, 4시간).
- **B**: 2026년 육지 ESS 중앙계약시장 공고(한국전력거래소 공고 제2026-05호, 2026-09-22)의 보상 구조를 적용한 가상 설비(50MW / 송전단 300MWh, 6시간).
- 둘 다 연구용 예시이며 실제 부지나 적격 사업이 아닙니다.
- 세금·차입·복잡한 금융구조는 제외했습니다.
- 할인율 7%는 검증된 한국 사업 WACC가 아닌 연구용 가정입니다.

**A 방법.**

- 시간별 SMP는 8,760행이지만 366일에 걸쳐 있습니다(1/1은 24시 없음, 12/31은 24시만 있음).
- 누락값을 채우지 않고 **완전한 364일**(1/2~12/30)만 쓰는 진단 표본입니다. 완전한 2024년 연간 실적이 아닙니다.
- 날마다 LP로 충방전을 결정합니다. 제약은 출력 100MW, 내부 SOC 0~400MWh, 편도 효율 √0.86, 자정 SOC=0, 하루 내부 방전량 ≤ 400MWh입니다.
- 가격은 완전예측을 가정합니다.
- 연간 수익은 일평균 × 350 운전일로 환산합니다. 재무 가정은 CAPEX 470,000원/kWh, O&M은 CAPEX의 2%/년, 열화는 매출을 연 2%씩 감액, 15년, 7%입니다.

**A 결과** (차익 이익 = 방전수익 − 충전비용, 고정 O&M 차감 전; USD는 1,350원 환산):

| 구분 | 364일 합계 | 일평균 | 연간 환산(×350) | 1년차 O&M | NPV |
|---|---|---|---|---|---|
| **daily-reset LP (기준 가정)** | $3.634M | $9,983 | $3.494M | $2.785M | **−$136.2M** |
| cycle 제한을 송전단 방전량 기준으로 (민감도) | $3.650M | $10,026 | $3.509M | $2.785M | −$136.1M |
| 연속 SOC, 일별 cycle 제한 유지 (진단) | $3.658M | $10,048 | $3.517M | $2.785M | −$136.0M |
| 기존 heuristic (실행 불가능한 일정, 비교용) | $3.911M | $10,745 | $3.761M | $2.785M | −$134.0M |

**검증.**

- A 테스트 14개가 통과했습니다: 손계산, 무거래 조건, 제약 위반 검사, solver 상태, 손익분기 재대입, 데이터 검사.
- 손익분기 CAPEX $60.1/kWh와 추가수익 $149.5/kW-yr를 다시 넣으면 |NPV| < 1원입니다.
- 과거 헤드라인 −$142.5M → −$136.2M 변화를 한 번에 한 가지씩 분해했습니다(단위 $M):

| 시나리오 범위 | 평균화 | 데이터 범위 | 운영방식 | cycle 정의 |
|---|---|---|---|---|
| −0.90 | +9.18 | +0.15 | −2.04 | −0.13 |

**A로 말할 수 있는 것.** 2024년 가격을 반복한다는 가정에서, 이 비용 구조는 가격수용자 차익거래만으로 CAPEX를 회수하지 못합니다. 15년 무할인 영업현금흐름은 약 $3.9M으로, CAPEX $139.3M에 비해 매우 작습니다.

**A로 말할 수 없는 것.** 실제 한국 ESS가 받는 보상, 미래 가격, 보조금 필요성이나 사회적 편익.

## 2쪽. B의 사업구조, 공식 확인 사항, 연구용 가정

**공고 원문에서 직접 확인한 사항** (인쇄 쪽 / PDF 쪽; 원문 파일은 저장소에 없음, `docs/source_manifest.md` 참조):

| 항목 | 원문 내용 | 근거 |
|---|---|---|
| 입찰 물량 | 10MW(60MWh) 초과 ~ 100MW(600MWh) 미만, 1MW 단위. 송전단 최대 방전용량과, 거래기간 동안 그 출력으로 6시간 방전 가능한 전력저장량 | p.1/3, p.22/24 |
| 가격·충방전 | 원/kW-h, 공급가능용량 기준 단위 고정비, 계약기간 불변·물가 미반영. "정산시 충전비용 및 방전수익은 미정산" | p.14/16, p.22/24, p.25/27 |
| 정산식 | 일간 정산금 = Σ(t=1~24) 계약가격 × 공급가능용량 × 이행률, 공급가능용량 = 최대전력저장량 ÷ 6, 월 단위 정산 | p.26/28 |
| 이행률 | 1 − {충전 미이행비율·α + 방전 미이행비율·(1−α)}, α = 충전 지시량 비중, 각 비율 상한 1 | p.26/28 |
| 기간 | 거래기간 15년(상업운전 개시일 포함), 준공기한 2029년 2월 | p.25/27 |
| 성능·가격조정 | 383 cycle/년 이상, 보증수명 70% 이상, 운전효율 65% 이상. 보증수명·운전효율이 입찰 점수 아래로 떨어지면 점수 기반으로 계약가격 하향 | p.5/7, p.26/28 |
| 보증수명과 KEC | 보증수명 = 최초 설계용량 대비 잔여용량 비율. 입찰물량은 KEC 512.1.2 고려. KEC 참고로 "운영 중간에 보증수명의 연장목적으로 설계 용량을 추가하지 않아야 함" 인용. KEC 제2025-052호 512.1.2는 정격방전용량 확보·이하 운영만 규정(위 문장 없음), 부칙은 공고일 시행 | 공고 p.22–23/24–25; KEC 523, 1177 |

**ATB 2024 v3 워크북과 웹본문 변환 PDF에서 확인한 사항** (시트 "Utility-Scale Battery Storage"):

- 모든 금액은 **2022$** 기준입니다(D10). 연도 열은 전망연도입니다.
- 기존 476.74는 **4시간** OCC 2023 = 1,906.96 $/kW(H108)를 4로 나눈 값입니다. **6시간** OCC 2023은 2,680.80 $/kW(H111)이고, kWh당 446.80입니다.
- OCC에는 계통연계비와 건설금융이 빠져 있습니다. ATB "CAPEX"(미국 $100/kW 계통연계비·건설금융 포함)는 6시간·2023년 행에서 OCC보다 7.5% 높지만, 한국 비용 추정치가 아닙니다.
- 고정 O&M = 0.025 × OCC(H128)이고, **augmentation을 포함해 15년간 정격용량을 유지**하는 비용입니다(웹본문). 저장 용량은 usable 기준, RTE는 0.85입니다.

**전력시장운영규칙(2026. 7.) 원문으로 확인한 사항** (인쇄/PDF 쪽):

- ① **급전지시가 없는 시간**: EFR = Max{1 − |발전단 계량값| ÷ 계약 최대방전용량, 0}, 허용오차 이내 대기 시 1. 모든 거래시간이 정산됩니다(별표2 Ⅰ.18, 531–532/549–550).
- ② **시간별 용량**: 송전단 방전가능전력량(EOSE)을 시간대별로 입찰하며 승인된 정비계획과 일치해야 합니다. 정산금 = 계약가격 × EOSE/6 × 이행률(별표4 6.6, 588–589/606–607).
- 거래수수료는 방전 계량값을 기준으로 부과하며, 요율은 KPX가 따로 정합니다(별표8 7.8.1, 634/652).

**여전히 확인되지 않은 사항**:

- 열화로 EOSE를 계약량보다 낮게 입찰할 때의 처리(찾지 못함).
- 공고의 설계용량 추가 제한이 열화 보충·동일 용량 교체에도 적용되는지, 추가 용량이 연도별 보증수명 평가에 반영되는지.
- 가상 사업에 적용될 KEC 판본(이전 경과조치는 인허가 신청 시점 기준이나, 가상 사업에는 그 시점이 없음).
- ESS 수수료의 부과 대상 거래량과 요율. 조사 메모의 일반 요율 0.1193원/kWh는 이 ESS 적용이 미확인이고 kW-h 정산량과 단위가 달라 모델에 넣지 않음.
- 표준계약조건: 이번 공개 검색에서 원문 미확보. 정정공고: KPX 공지사항 1쪽(9/22–23)·공개 검색에서 미발견(9/27 기준, 전체 부재 아님). 설명회: 9/30 예정.

**B 연구용 가정** (모두 명시적 가정):

| 항목 | 값 | 성격 |
|---|---|---|
| 설비 | 50MW / 송전단 300MWh | 가상; 입찰 범위 안 |

## 3쪽. 손익분기 단가의 계산 내역과 조건부 민감도

**계산 내역** (⚠ 아래 p\*는 모든 시간 EFR = 1과 계약량 EOSE를 가정한 **조건부 결과**입니다. 용량 유지 방식의 계약 적합성도 확인되지 않았습니다. 정산식은 운영규칙으로 확인됨):

| 단계 | 값 |
|---|---|
| 계약 출력 | 50MW = 50,000kW |
| 송전단 에너지 | 300MWh = 300,000kWh |
| 내부 용량 (참고용, 비용에는 미사용) | 300,000 ÷ (√0.86 × 1) ÷ 1.0 = 323,498kWh |
| OCC 기준 초기투자비 (총사업비 아님) | 446.7998 × 1,350 × 300,000 = 1,809.539억원 |
| 연간 O&M (augmentation 포함) | 45.238억원 |
| 할인계수 합 Σ1.07^−y (y=1..15) | 9.107914 |
| 할인된 비용 합 | 1,809.539억 + 45.238억 × 9.107914 = **2,221.567억원** |
| 연간 정산물량 | 50,000kW × 8,760h × f(=1.00) = 4.38억 kW-h (연간 단순화) |
| 할인된 정산물량 합 | 4.38억 × 9.107914 = **39.8927억 kW-h** |
| **손익분기 단가 p\*** | 2,221.567억 ÷ 39.8927억 = **55.69원/kW-h ⚠ 조건부** |
| p\*에서의 연간 계약수입 / 순현금흐름 | 243.92억원 / 198.68억원 |

- **비용 갱신 전후** (다른 입력은 고정: f=1.00, 8,760시간, 명목 7%, 환율 1,350원, 15년):

| 사례 | ATB 셀 | $/kWh (2022$) | p\* ⚠ 조건부 |
|---|---|---|---|
| 이전 (재현용): 4시간 OCC를 6시간 설비에 적용 | H108/4 | 476.74 | 59.42 |
| **비용 갱신 (새 기준)**: 6시간 OCC, 같은 2023년 열 | H111/6 | 446.80 | **55.69 (−6.3%)** |
| 별도 시나리오: 6시간 OCC, 2029년 Moderate | N111/6 | 311.26 | 38.79 (−34.7%) |

- **손계산 대조.** 이전 사례에서 59.42 × 50,000 × 8,760 = 26,025,960,000원이고, 모델과의 차이 145,699원은 p\* 반올림분과 같습니다. 8,760시간은 연간 단순화이지 시장규칙이 아닙니다.
- **점검한 오류 유형.** MW·MWh 단위 변환, 환율 중복, 6시간 요건과 정산시간의 혼동, 공급가능용량과 SOC의 혼동, 내부/usable 이중 환산, 설치비와 팩 비용의 중복을 확인했고 모두 해당 없음입니다.
- **O&M 처리 구분.** 비용 갱신에서는 O&M을 새 OCC의 2.5%로 다시 산정했습니다(ATB 규칙). 아래 표의 O&M ±25%는 그 값을 기준으로 한 별도 민감도입니다. CAPEX 민감도는 O&M을 고정한 단일 변수 분석입니다.
- **두 계산 경로는 분리돼 있습니다.** 시간별 정산은 운영규칙 산식(`hourly_efr_rules`)으로 구현했고, 공고 형식 함수는 공고에 정의가 없는 경우 오류를 그대로 냅니다. 손익분기 단가를 계산하는 연간 경로는 어느 시간 함수도 호출하지 않습니다. EOSE가 계약량이고 모든 시간 EFR = 1이면 운영규칙의 정산금이 연간 모델(f = 1)과 정확히 같으므로 **55.69는 변하지 않습니다**. 실제 급전·계량 자료가 없으므로 f는 여전히 가상 값입니다.

**조건부 민감도** (한 번에 한 변수; 값은 가상 예시이며 전망·공식 범위·발생확률이 아님; ⚠ 모든 값이 조건부):

| 변수 | 0.75 / 1.00 | 1.00 / 0.95 | 1.25 / 0.90 |
|---|---|---|---|
| CAPEX 배수 (O&M 고정) | 44.35 (−20.4%) | 55.69 ⚠ | 67.03 (+20.4%) |
| 가상 유효 지급계수 f | 55.69 ⚠ | 58.62 (+5.3%) | 61.88 (+11.1%) |
| 총 고정 O&M 배수 (증설비 포함) | 53.11 (−4.6%) | 55.69 ⚠ | 58.27 (+4.6%) |

- 비용이 같을 때 p\*(f) = p\*(1)/f가 정확히 성립합니다(55.6886/0.95 = 58.620, /0.90 = 61.876). 이는 산술 검증이며 미이행 페널티 규정을 재현한 것이 아닙니다.
- 공급가능용량 감소와 지급계수 하락은 따로 다루며 중복 반영하지 않았습니다.
- CAPEX × f 조합 표와 그림은 `outputs/contract_breakeven_grid.csv`와 `figures/contract_breakeven_sensitivity.png`에 있습니다.

## 4쪽. 해석의 한계와 검토 요청

**해석.**

- A는 "시장가격만으로 투자비가 회수되는가"에 답합니다.
- B는 "명시된 비용·지급 가정이라면 얼마의 고정 보상이 필요한가"에 조건부로 답합니다.
